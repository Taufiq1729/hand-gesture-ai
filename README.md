# AI Gesture Control Application

This application allows you to control your system using hand gestures through your webcam.

## Setup

1. Create a virtual environment with a compatible Python version (e.g., 3.10 or 3.11), as `mediapipe` does not yet support Python 3.13+.
   ```bash
   # Replace python3.10 with your installed compatible Python version
   python3.10 -m venv venv
   source venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main application:
```bash
python src/main.py
```
